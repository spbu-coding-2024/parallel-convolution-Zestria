# Image Convolution CLI Utility (Sequential)

Однопоточная утилита командной строки для применения фильтров свёртки к изображениям. Представляет собой базовую (последовательную) реализацию алгоритма.

---

## Синтаксис запуска

```bash
./image_conv_cli [--kernel <name>] <input.png> <output.png>

```

---

## Параметры и флаги

| Параметр | Описание |
| --- | --- |
| `--kernel <name>` | Название ядра свёртки (необязательный параметр; например: `blur_3x3`, `blur_5x5`, `motion_blur_9x9`, `identity_3x3`). |
| `<input.png>` | Путь к исходному файлу изображения. |
| `<output.png>` | Путь для сохранения обработанного файла. |

---

## Примеры использования

### 1. Запуск с ядром по умолчанию

Применить фильтр свёртки с параметрами ядра по умолчанию:

```bash
./image_conv_cli input.png output.png

```

### 2. Выбор конкретного ядра свёртки

Применить фильтр `blur_5x5` к входному изображению:

```bash
./image_conv_cli --kernel blur_5x5 input.png output.png

```

---

## Получение справки

Запустите программу без аргументов или с передачей некорректного флага, чтобы вывести список всех поддерживаемых в данной сборке ядер свёртки:

```bash
./image_conv_cli

```
