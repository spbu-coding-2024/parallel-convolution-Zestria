# Image Convolution CLI Utility

Утилита командной строки для применения фильтров свёртки к изображениям в одиночном или конвейерном (pipeline) режиме с использованием многопоточности OpenMP.

---

## Синтаксис запуска

Утилита поддерживает два основных режима работы: **обработка одиночного изображения** и **пакетная конвейерная обработка**.

### 1. Обработка одиночного изображения

```bash
./image_conv_cli [--kernel <name>] [--partition <name>] [--threads <n>] [--schedule <name>] <input.png> <output.png>

```

### 2. Пакетная конвейерная обработка (Pipeline)

```bash
./image_conv_cli [--kernel <name>] [--partition <name>] [--threads <n>] [--schedule <name>] [--window <n>] --pipeline <in_pattern> <out_pattern> <count>

```

---

## Параметры и флаги

| Параметр | Описание |
| --- | --- |
| `--kernel <name>` | Название ядра свёртки (например: `blur_3x3`, `blur_5x5`, `motion_blur_9x9`, `identity_3x3`). |
| `--partition <name>` | Стратегия параллельного разбиения изображения (например: `row`, `column`, `pixel`, `tile`). |
| `--threads <n>` | Количество рабочих потоков OpenMP (число $> 0$). |
| `--schedule <name>` | Тип планировщика распределения итераций OpenMP (например: `static`, `dynamic`, `guided`). |
| `--window <n>` | Размер окна буферизации (максимальное количество одновременно находящихся в обработке изображений). Используется только в режиме `--pipeline`. |
| `--pipeline` | Флаг включения конвейерной обработки пакета изображений. Принимает шаблоны имен и количество файлов. |
| `<input.png> / <output.png>` | Пути к входному и выходному файлам (для одиночного режима). |
| `<in_pattern> / <out_pattern>` | Шаблоны путей для пакета файлов. Шаблон должен содержать спецификатор `%d`, который автоматически заменяется на индекс изображения от `0` до `count - 1`. |
| `<count>` | Количество обрабатываемых изображений в пакете. |

---

## Примеры использования

### Простая обработка одного файла

Обработать файл `input.png` с параметрами по умолчанию и сохранить результат в `output.png`:

```bash
./image_conv_cli input.png output.png

```

### Параллельная обработка с явным указанием ядра и потоков

Применить ядро `blur_5x5` на 8 потоках с разбиением по строкам (`row`) и динамическим планировщиком:

```bash
./image_conv_cli --kernel blur_5x5 --partition row --threads 8 --schedule dynamic input.png output.png

```

### Пакетная обработка серии файлов через Pipeline

Обработать 20 изображений вида `assets/image_0.jpg` … `assets/image_19.jpg` с окном конвейера из 4 слотов:

```bash
./image_conv_cli --kernel motion_blur_9x9 --threads 4 --window 4 --pipeline "assets/image_%d.jpg" "output/conv_%d.png" 20

```

## Получение справки

Для просмотра полного списка доступных ядер свёртки, способов разбиения и типов планировщиков запустите утилиту без аргументов или с неверным флагом:

```bash
./image_conv_cli

```
